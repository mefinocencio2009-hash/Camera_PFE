# 📸 Camera_PFE — Captura com Identificação

Aplicação web que acessa a câmera do dispositivo via `getUserMedia`, realiza
uma captura, aplica um **efeito visual** e grava, sobre a própria fotografia,
a **identificação do aluno** e a **data/hora** da captura. Todo o processamento
acontece no navegador, com Canvas 2D — sem bibliotecas ou frameworks.
